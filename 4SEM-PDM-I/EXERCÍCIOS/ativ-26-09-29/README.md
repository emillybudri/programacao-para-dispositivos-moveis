# 📱 Atividade 29/09 - Aplicativos Android Jetpack Compose

Este diretório contém os aplicativos Android desenvolvidos como parte da atividade de **29/09** na disciplina de **Programação para Dispositivos Móveis (PDM)**.

---

## 📂 Projetos Incluídos

1. **[Lista de Compras](./lista-compras)**: Aplicativo para criação e gerenciamento dinâmico de listas de compras.
2. **[Controle de Viagens](./controle-viagens)**: Aplicativo para planejamento financeiro, cálculo de combustível e divisão de despesas de viagem.
3. **[APKs Prontos](./apks)**: Instalação rápida nos dispositivos Android.
4. **[Vídeos e GIFs](./videos)**: Registros de telas e demonstrações em GIF aceleradas.
